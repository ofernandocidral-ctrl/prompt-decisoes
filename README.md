# Prompt Decisões

Um prompt que cria uma memória de decisões para o Claude (ou o Codex). Para cada decisão importante ficam registrados as opções consideradas, o motivo, quem decidiu e a condição que faria rever a escolha. Depois, o Claude consulta essa memória e mostra qual motivo ainda vale.

## Como usar

1. Crie uma pasta vazia no computador, por exemplo `minhas-decisoes`.
2. Abra a pasta no Claude Code (ou no Codex), copie o bloco "O prompt" do arquivo [PROMPT-DECISOES.md](PROMPT-DECISOES.md), cole na conversa e envie.
3. Responda as perguntas. Ele faz uma fase de cada vez.

## Aviso sobre dados sensíveis

Não registre prontuários, documentos de pacientes ou clientes, senhas ou chaves. Use códigos ("Paciente A"). Dados de saúde exigem cuidado extra: confirme com quem cuida da proteção de dados na sua empresa.
